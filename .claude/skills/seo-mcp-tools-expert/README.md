# seo-mcp-tools-expert

Expert guide for using seo-mcp MCP tools effectively.

## Purpose
Teaches Claude HOW to use the seo-mcp MCP tools — which tools to pick, in what order, with what parameters. This skill focuses on tool usage, not SEO concepts (see other skills for that).

## Activation Triggers
This skill activates when the user mentions: using seo-mcp tools, SEO audit, check my SEO, analyze this page, running an audit, tool selection, which tool to use, MCP tools for SEO.

## Files
| File | Lines | Description |
|------|-------|-------------|
| SKILL.md | ~300 | Tool categories, common workflows, parameter reference, common mistakes |
| ANALYSIS_GUIDE.md | ~250 | Detailed guide for 7 page analysis tools with response formats |
| PERFORMANCE_GUIDE.md | ~200 | Core Web Vitals and mobile tools with interpretation guide |
| GENERATION_GUIDE.md | ~200 | Schema, robots.txt, and meta tag generation tools |
| AUDIT_WORKFLOW_GUIDE.md | ~200 | Complete audit workflow with decision tree and progressive analysis |

## MCP Tools Covered
All 29 seo-mcp tools:
- 11 analysis tools (analyze_page, analyze_headings, analyze_images, analyze_internal_links, extract_schema, analyze_robots_txt, analyze_sitemap, audit_security_headers, analyze_url_structure, validate_hreflang, audit_accessibility)
- 2 performance tools (check_core_web_vitals, check_mobile_friendly)
- 4 research tools (research_keywords, analyze_serp, analyze_backlinks, analyze_domain_authority)
- 3 GSC tools (gsc_performance, gsc_index_coverage, gsc_sitemaps)
- 3 generation tools (generate_schema, generate_robots_txt, generate_meta_suggestions)
- 6 crawler tools (crawl_site, crawl_status, crawl_results, detect_orphan_pages, compare_crawls, list_crawls)
