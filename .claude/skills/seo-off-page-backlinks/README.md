# seo-off-page-backlinks

Expert guide for off-page SEO, backlink analysis, and link building strategy.

## Purpose

Teaches Claude how to analyze backlink profiles, assess link quality, plan link building campaigns, identify toxic backlinks, interpret domain authority metrics, optimize anchor text distribution, perform competitor backlink gap analysis, and create disavow files. Covers the full lifecycle of off-page SEO from strategic planning through execution and cleanup.

## Activation Triggers

This skill activates when the user mentions: backlinks, backlink profile, backlink analysis, domain authority, domain rating, link building, link quality, anchor text, toxic links, disavow, link outreach, competitor backlinks, backlink gap, off-page SEO, referring domains, link equity, PageRank, link velocity, PBN, link farm, HARO, guest posting, digital PR, broken link building, resource page outreach, skyscraper technique.
