# بخشِ اول — ماژولِ «اخبار و قیمت‌ها» (زیرسیستمِ قیمت‌ها) ✅

این فایل توضیح می‌ده چی ساخته شده، چطور نصبش کنی، و چه چیزی هنوز نیاز به تنظیمِ
دستی داره. طبقِ درخواست، **فقط بخشِ اول** (استخراجِ قیمت + ساختِ عکسِ گرافیکی)
کامل شده؛ بخشِ تبلیغات و اخبار در پنل به‌صورتِ «به‌زودی» نمایش داده می‌شن و در
فازهای بعدی تکمیل می‌شن.

## چی اضافه شد؟

یک پکیجِ کاملاً ایزوله زیرِ `bot/auto_poster/` با دیتابیسِ مجزا
(`data/auto_poster.db`) که هیچ جدول/کش/فایلی با هسته‌ی ری‌پست مشترک نداره:

- `config.py` — لینک‌ها، رجیستریِ ۴۷ نمادِ پیش‌فرض (۲۰ فیات، ۹ کریپتو، ۹ طلا/سکه، ۹ بازارِ جهانی)
- `db.py` — تنظیمات/نمادها/زمان‌بندی/لاگ (SQLite جدا)
- `scraper.py` — aiohttp، دیدوپِ درخواست‌ها روی URL یکسان، محاسبه‌ی نرخِ مرجعِ دلار
- `formatter.py` — فرمتِ سه‌رقمی، محاسبه‌ی قیمتِ غایب (دلاری⇄تومانی)، Sparkline SVG
- `renderer.py` — Jinja2 + Playwright، Element Screenshot با ارتفاعِ داینامیک
- `poster.py` — کشِ ۵ دقیقه‌ای + Fallback، ترتیبِ ارسالِ متن→عکس→جداکننده طبقِ اسپک
- `scheduler.py` — تسکِ asyncio جدا: پیش‌واکشیِ ۱ دقیقه‌ی قبل + انتشارِ سرِ ساعت
- `menu.py` / `keyboards.py` — پنلِ مدیریتِ ادمین (کاملاً با پیشوندِ کالبکِ `npz:`)
- `assets/{currency,crypto,gold,market}/` — همون ۴ قالبِ HTML/CSS/آیکون/فونتی که فرستادی، به‌علاوه‌ی `template.html` (نسخه‌ی Jinja2)

### تغییراتِ حداقلی در هسته (فقط نقطه‌ی اتصال، بدونِ دست‌زدن به منطقِ ری‌پست)
- `bot/keyboards.py`: یک ردیفِ جدید «📊 اخبار و قیمت‌ها» به `MAIN_BUTTONS` اضافه شد (فقط برای ادمین دیده می‌شه).
- `bot/handlers/__init__.py`: رجیستریِ دکمه‌های منو یکپارچه شد (`kb.MAIN_MENU_REGEX`) + یک هندلرِ ورودیِ متنیِ مجزا برای این ماژول (گروهِ `-1`، فقط وقتی خودِ ماژول منتظرِ ورودیه واردِ عمل می‌شه).
- `bot/handlers/menu.py`: ۳ خط برای دیسپچ‌کردنِ کلیدِ `newsprice` و پیشوندِ کالبکِ `npz:` به همین پکیج.
- `main.py`: یک خط (`_auto_poster.setup(application)`) که تسکِ asyncio جدا رو استارت می‌کنه.
- `requirements.txt`: اضافه‌شدنِ `aiohttp`, `Jinja2`, `playwright`.

## نصب

```bash
pip install -r requirements.txt
playwright install chromium --with-deps
```

سپس ربات رو مثلِ همیشه اجرا کن: `python3 main.py`

## استفاده

۱. توی چتِ ادمین با ربات، دکمه‌ی «📊 اخبار و قیمت‌ها» رو بزن → «💰 تنظیماتِ قیمت‌ها»
۲. اول «🎯 تنظیمِ کانالِ مقصد» رو بزن و آیدیِ عددیِ کانالی که ربات توش ادمینه رو بفرست
۳. با «⏱ تنظیمِ زمان‌بندی» ساعت‌های انتشار رو مشخص کن (پیش‌فرض: 09:00, 13:00, 18:00, 22:00)
۴. با «📝 مدیریتِ نمادها» هر نمادی که لازم نداری رو خاموش کن
۵. برای تستِ فوری، «▶️ انتشارِ دستی الآن» رو بزن

## ⚠️ نکته‌ی مهم و صادقانه درباره‌ی اسکرِیپر

من به‌خاطرِ محدودیتِ محیطِ توسعه (بدونِ دسترسیِ اینترنت) نتونستم `scraper.py` رو
مستقیماً روی HTMLِ زنده‌ی tgju.org تست کنم. منطقِ استخراج (بر اساسِ ویژگیِ
`data-market-row` که tgju.org معمولاً استفاده می‌کنه) پیاده‌سازی و به‌صورتِ
انتزاعی تست شده، ولی **حتماً لازمه یک‌بار روی سرورِ خودت با اجرای واقعی چک کنی**.
اگه انتخابگرها (`selector_hint`) با ساختارِ فعلیِ سایت نخوند، فقط کافیه توی
دیتابیسِ `auto_poster.db` (جدولِ `symbols`، ستونِ `selector_hint`) مقدارشون رو
اصلاح کنی — لازم نیست کدی تغییر کنه. اگه بخوای، توی همون جلسه‌ی تست می‌تونم
باهم لاگ‌های خطا رو بررسی کنم و انتخابگرها رو دقیق کنم.

همه‌ی مسیرهای خطا (خرابیِ سایت، تغییرِ ساختار، قطعیِ شبکه) با `try/except`
پوشش داده شدن و فقط لاگ می‌کنن — هیچ‌کدوم ربات یا حتی خودِ این ماژول رو
متوقف نمی‌کنن (Fallback به کشِ قبلی).
