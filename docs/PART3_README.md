# بخشِ سوم و آخر — ماژولِ «استخراج و انتشارِ اخبار» ✅

با این بخش، هر ۳ ماژولِ درخواستی (قیمت‌ها، تبلیغات، اخبار) کامل شدن. 🎉

## چی اضافه شد؟

باز هم همه‌چیز داخلِ همون پکیجِ ایزوله (`bot/auto_poster/`) و همون دیتابیسِ
مجزا، با ۲ جدولِ جدید (`news_sources`, `news_queue`):

- `news_scraper.py` — استخراجِ هوشمند از ۲ نوع منبع:
  - **سایتِ خبری:** با `newspaper3k` (فقط متنِ اصلی + عکسِ شاخص)
  - **کانالِ تلگرام:** با پارسِ صفحه‌ی وبِ `t.me/s/username` (بدونِ نیاز به API/توکنِ اضافه)
  - یه پاک‌سازیِ سبک هم روی متن انجام می‌شه: خطوطِ «منبع:»، «ادامه مطلب»، آیدیِ تنهای کانال حذف می‌شن.
- `news.py` — منطقِ صفِ تایید:
  - اگه «تاییدِ ادمین» روشن باشه → خبر با عکس/ویدیو (اگه داشته باشه) + ۳ دکمه به پی‌وی همه‌ی ادمین‌ها (`ADMIN_IDS`) ارسال می‌شه: **✅ تایید و انتشار** / **✏️ ویرایش متن** / **❌ لغو**.
  - «✏️ ویرایش متن» → ربات متنِ جدید رو می‌پرسه؛ بعد از دریافت، بلافاصله در کانال پست می‌شه.
  - اگه «تاییدِ ادمین» خاموش باشه → مستقیم در کانالِ مقصد پست می‌شه.
- `db.py` — مدیریتِ منابع (افزودن/حذف/روشن‌خاموش) + صفِ اخبار (وضعیت: pending/approved/rejected/posted)
- `scheduler.py` — چکِ منابع بر اساسِ «بازه‌ی زمانی» (نه ساعتِ ثابت؛ مثلاً هر ۳ ساعت)، کاملاً مستقل از زمان‌بندیِ قیمت‌ها و تبلیغات
- پنلِ کامل: وضعیت / افزودنِ منبع (سایت یا کانال) / لیستِ منابع (روشن‌خاموش + حذف) / بازه‌ی چک / تاییدِ ادمین (روشن‌خاموش) / کانالِ مقصد / صفِ درحالِ‌انتظار

## ⚠️ نکاتِ صادقانه (لطفاً قبل از فعال‌کردن بخون)

۱. **تستِ زنده لازمه:** مثلِ اسکرِیپرِ قیمت‌ها، این بخش هم بدونِ اینترنت نوشته
   شده. منطقِ پارسِ `t.me/s/` استانداردِ شناخته‌شده‌ست و تستِ واحدی روی یک
   نمونه‌ی HTMLِ دستی زدم (پاس شد)، ولی حتماً با یک کانالِ واقعی امتحان کن.

۲. **`newspaper3k` برای سایت‌های فارسی:** این کتابخانه برای زبانِ فارسی
   استانداردهای RSS/HTMLِ رایج رو خوب تشخیص می‌ده ولی صددرصد نیست؛ بعضی
   سایت‌های خیلی سفارشی ممکنه نیاز به تنظیمِ اضافه داشته باشن. اگه سایتِ
   خاصی جواب نداد، بگو تا selectorِ اختصاصی براش بنویسم.

۳. **پستِ عکس/ویدیو با URL:** برای سادگی و سرعت، لینکِ عکس/ویدیوِ استخراج‌شده
   مستقیم به تلگرام پاس داده می‌شه (بدونِ دانلودِ دستی)؛ خودِ سرورهای تلگرام
   اون رو fetch می‌کنن. اگه لینک منقضی بشه یا سایت دسترسی مستقیم به فایل رو
   ببنده، ربات به‌صورتِ خودکار فالبک می‌کنه به ارسالِ فقط‌متن (چیزی گم نمی‌شه).

۴. **صفِ تایید در پی‌وی:** اگه ربات با ادمین چت نداشته باشه (Start نزده)،
   تلگرام اجازه‌ی ارسالِ پیام نمی‌ده. حتماً قبل از فعال‌کردن، با ربات از پی‌وی
   `/start` بزن.

## تست‌هایی که زدم
- CRUDِ کاملِ منابع و صفِ اخبار (افزودن/فعال‌غیرفعال/حذف/آپدیتِ وضعیت) ✅
- پاک‌سازیِ متن (حذفِ «منبع:»، «ادامه مطلب»، آیدیِ تنها) ✅
- نرمال‌سازیِ لینکِ کانالِ تلگرام (۳ فرمتِ ورودی → همه به `t.me/s/username`) ✅
- پارسِ HTMLِ نمونه‌ی `t.me/s/` (فیلترِ پیام‌های قدیمی‌تر از `last_seen_id`، استخراجِ متن+عکس) ✅
- فرمتِ کپشن با محدودیتِ طول (۱۰۲۴ برای عکس/ویدیو، ۴۰۹۶ برای متنِ خالی) + دکمه‌های تایید ✅

## نصب

علاوه بر مراحلِ بخشِ اول، این یکی رو هم اضافه کن:
```bash
pip install -r requirements.txt
```
(دیگه نیازی به دستورِ جدا نیست؛ `newspaper3k` و `lxml_html_clean` به `requirements.txt` اضافه شدن)

## جمع‌بندیِ کل پروژه

هر ۳ ماژول کاملاً ایزوله، با یک نقطه‌ورودی (دکمه‌ی «📊 اخبار و قیمت‌ها») و یک
دیتابیسِ مشترکِ مجزا (`auto_poster.db`، جدا از دیتابیسِ اصلیِ ری‌پست) پیاده‌سازی
شدن. هسته‌ی ری‌پست فقط با ~۱۰ خط دست‌خورده (همه‌شون نقطه‌اتصال، نه منطق).
