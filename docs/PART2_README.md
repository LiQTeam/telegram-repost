# بخشِ دوم — ماژولِ «تبلیغات و تبادلات» ✅

## چی اضافه شد؟

همه‌چیز داخلِ همون پکیجِ ایزوله‌ی `bot/auto_poster/` و همون دیتابیسِ مجزا
(`data/auto_poster.db`)، فقط با ۲ جدولِ جدید (`ads_buttons`, `ads_schedule`):

- `ads.py` — ساختِ پیام (کپشن + دکمه‌های شیشه‌ای ۲تایی در هر ردیف) و ارسالِ آن
- `db.py` — اضافه‌شدنِ CRUD کاملِ دکمه‌ها و زمان‌بندیِ تبلیغات
- `scheduler.py` — تیکِ زمان‌بندیِ تبلیغات مستقل از قیمت‌ها (هر دو در یک تسکِ asyncio، ولی کاملاً جدا از هم؛ خاموش‌بودنِ یکی روی اون یکی تاثیری نداره)
- `menu.py` / `keyboards.py` — پنلِ کاملِ مدیریتِ تبلیغات:
  - 🟢/🔴 وضعیت
  - ➕ افزودنِ دکمه (۲ مرحله: اول اسم، بعد لینک — لینک باید با `http(s)://` یا `t.me/` شروع بشه)
  - 🗑 حذف / ✏️ ویرایشِ هر دکمه (لیست با دکمه‌ی حذف و ویرایش کنارِ هم)
  - ✍️ ویرایشِ متنِ کپشن (HTML مجاز)
  - ⏱ تنظیمِ زمان‌بندی (چندین ساعت در روز، مستقل از زمان‌بندیِ قیمت‌ها)
  - 🎯 تنظیمِ کانالِ مقصد (مثلِ بخشِ قیمت‌ها)
  - ▶️ انتشارِ دستی الآن

## نکاتِ فنی

- دکمه‌ها همیشه ۲تا در هر ردیف چیده می‌شن (ردیفِ آخر اگه فرد باشه، تک می‌مونه) — دقیقاً طبقِ اسپک.
- اگه هیچ دکمه‌ای ثبت نشده باشه، انتشار (چه دستی چه زمان‌بندی‌شده) با پیامِ خطا لغو می‌شه؛ چون تبلیغِ بدون دکمه بی‌معنیه.
- کپشنِ پیش‌فرض (اگه ویرایش نکنی) یه متنِ نمونه‌ست؛ از همون اول می‌تونی عوضش کنی.
- تمام مسیرهای خطا (چت نامعتبر، لینکِ اشتباه، دکمه‌ی خالی) پیامِ روشن به ادمین می‌ده و چیزی رو کرش نمی‌کنه.

## تست‌هایی که زدم
- CRUD کاملِ دکمه‌ها (افزودن/ویرایش/حذف) + زمان‌بندی (افزودن/حذف/جلوگیری از تکراری) ✅
- منطقِ چیدمانِ ۲تایی دکمه‌ها با ۷ دکمه‌ی نمونه → خروجی: ۳ ردیفِ ۲تایی + ۱ ردیفِ تکی ✅
